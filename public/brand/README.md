# Minor Works brand folder

One folder per project: `brand/<id>/mark.svg` is the square icon used in the shared footer
(`manifest.json` points at these) and `colors.json` holds that project's palette where known.

- `contact-sheet.png` shows the whole set together.
- Wordmarks, full logos and screenshots live in `/logos` and `/screenshots`.
- To change an icon: replace its `mark.svg` and commit. The footer on every site picks it up.
- Keep marks square (viewBox 0 0 64 64) with a rounded tile, flat colors and no text.
- Rank and File uses its original navy grid mark. Margin is an orange M with the ink check cut from its own outline.
